# Family Gateway（家庭网关门户）

一个跑在家里 Mac mini 上的**自建家庭服务门户**，把家里常用的自托管服务  
（影视、音乐、下载、智能家居、AI 网关）聚合到一个入口，带统一状态监控和  
一键升级。

> 本项目为**个人自建、非商业**用途，仅供家庭成员在局域网内使用，  
> 不对外提供服务，无任何收费、广告或增值服务。

## 功能概览

### 1. 统一门户

- 服务卡片聚合，按「影音 / 下载 / 智能家居 / 工具」分类
- 每个服务带健康探针（HTTP / TCP），状态灯实时反映可用性
- 支持 iframe 内嵌（免密直通代理）或新标签页打开

### 2. 状态监控看板

- 宿主指标：CPU / 内存 / 磁盘 / 网络 / 温度 / 风扇 / 功耗
- 容器指标：逐容器 CPU、内存、运行时长
- 历史曲线与快照
- 布局可拖拽调整（GridStack），支持内容自适应高度

### 3. 一键升级

- 对比本地镜像 digest 与远端 registry，判断是否有新版本
- 两类服务分别处理：**镜像型**（pull + up -d）与 **npm 型**（构建 + up -d）
- 升级白名单机制：只有「有远程镜像 / 失败不拖垮门户 / 升级确有收益」的服务才纳入
- 更新说明自动清洗并翻译为中文（MyMemory）

### 4. 下载器按需启停

- qBittorrent / aria2 / AriaNg 空闲 5 分钟后自动停止容器，点击即唤醒
- 按「最后一次使用时间」回收，避免误杀

### 5. 影视聚合播放

- 自建 LibreTV 镜像，聚合多个影视资源站
- 播放器为 ArtPlayer，扩展了**弹幕**与**投屏**能力

## 影视模块：弹幕功能说明

影视模块基于开源项目 [LibreTV](https://github.com/LibreSpark/LibreTV)  
（TypeScript + Next.js）自行构建镜像，做了三处改动：

1. 引入 `artplayer-plugin-danmuku`（弹幕）与 `artplayer-plugin-chromecast`（投屏）
2. 在播放器 `plugins` 配置中挂载上述插件（ArtPlayer 原生支持 AirPlay）
3. 新增服务端路由 `/api/danmaku`，**代理弹弹play 开放弹幕网络 API**

第 3 点的设计考虑：

- 弹弹play 开放平台要求每次请求携带 `AppId` + 时间戳 + 签名，  
  签名算法为 `base64(sha256(AppId + Timestamp + Path + AppSecret))`
- `AppSecret` 若进入前端构建产物即等于公开，因此签名必须在服务端完成
- 未配置凭据时接口返回 `{configured:false, list:[]}`，播放器静默跳过，  
  **播放功能完全不受影响**

弹幕来源为「弹弹play 开放弹幕网络」（<https://www.dandanplay.com>），  
本项目按官方要求做了以下约束：

- 仅在用户点播某一集时按需拉取，不做批量抓取、不下载弹幕库
- 剧名 → 剧集 ID 的匹配结果缓存 30 分钟，弹幕正文缓存 10 分钟
- 弹幕功能完全免费，不作为任何付费点
